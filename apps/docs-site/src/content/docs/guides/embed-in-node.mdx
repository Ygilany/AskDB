<p class="doc-lede">Add AskDB to a TypeScript service. It generates checked SQL from a question and hands it back. Your service runs it through its own connection pool against a read-only role.</p>

## Wire it into a handler

There are two ways to give AskDB a model, and both return the same result. Pick by who owns your provider configuration ([Bring your own model](/guides/bring-your-own-model/#which-should-i-use) compares them):

- **With your config:** `createAskDb()` from `@askdb/client` resolves the schema, model and dialect from `askdb.config.ts`, the file `askdb init` scaffolded and the CLI and Studio read.
- **With your own model:** `ask()` from `@askdb/core` takes a Vercel AI SDK model that your app builds, and reads no config.

### With your config: `createAskDb()`

<InstallTabs pkgs="@askdb/client @askdb/core @askdb/config ai @ai-sdk/openai pg" />

| Package | Why |
| --- | --- |
| `@askdb/client` | `createAskDb()` — resolves the schema, model, and dialect from config. |
| `@ai-sdk/openai` | The AI SDK package for the provider your config selects. Swap it for `@ai-sdk/anthropic`, `@ai-sdk/google`, or `@ai-sdk/azure` (the Vercel AI Gateway needs none). AskDB loads it on first use. |
| `@askdb/config` | Loads `.env` and `askdb.config.ts` at startup. |
| `@askdb/core`, `ai` | With `@askdb/config`, the required peer dependencies of `@askdb/client` (`ai` at AI SDK 7). npm and pnpm add them for you; Yarn doesn't, so list them. |
| `pg` | The Postgres driver. AskDB doesn't open the connection; your app does. |

Call `createAskDb` once at startup, then `askdb.ask(question)` per request:

```ts
// ask-handler.ts
import { createAskDb } from "@askdb/client";
import { bootstrapAskDbEnv, getAskDbRuntimeConfig } from "@askdb/config";
import { Pool } from "pg";

bootstrapAskDbEnv({ cwd: process.cwd() });

const askdb = createAskDb({
  config: getAskDbRuntimeConfig(),                 // ai.provider picks the model
  schema: { path: "./my-app.schema" },             // or set host.schemaPath in config and omit
});

// Connect as a read-only, least-privilege role, with a statement timeout.
const pool = new Pool({
  connectionString: process.env.DATABASE_URL,
  statement_timeout: 5000,
  max: 10,
});
// An idle client whose connection drops emits on the pool; without a listener, the process exits.
pool.on("error", (err) => console.error({ err }, "idle database client error"));

// Runs one generated statement in a read-only transaction.
async function runReadOnly(sql: string, params: unknown[] = []) {
  const client = await pool.connect();
  // A dropped connection then fails the query instead of crashing the process.
  const onError = () => undefined;
  client.on("error", onError);
  try {
    await client.query("BEGIN READ ONLY");
    // queryMode "extended" sends the statement on its own, so a stacked second statement fails.
    // A variable, not an inline object: @types/pg doesn't declare queryMode.
    const query = { text: sql, values: params, queryMode: "extended" };
    const { rows } = await client.query(query);
    return rows;
  } finally {
    await client.query("ROLLBACK").catch(() => undefined);
    client.off("error", onError);
    client.release();
  }
}

export async function askQuestion(question: string) {
  const { sql, tenantParams } = await askdb.ask(question);

  // Audit hook — log every question and generated SQL.
  console.log({ question, sql });

  // `sql` runs with `tenantParams`, which is empty unless you pass a tenant scope.
  const rows = await runReadOnly(sql, tenantParams ?? []);
  return { sql, rows };
}
```

`./my-app.schema` is a **directory**, not a file — `<name>.schema/` is AskDB's convention for the introspected-and-enriched artifact. The schema loads on the first `ask()` and stays in memory on the client; call `askdb.reload()` if the artifact changes while the process runs.

To serve several schemas from one client, pass `schema` per call.

### With your own model: `ask()`

<InstallTabs pkgs="@askdb/core ai @ai-sdk/openai pg" />

`ai` is a required peer dependency of `@askdb/core` (AI SDK 6 or 7) — your app owns its version.

All six built-in dialects are built into `@askdb/core` — install `@askdb/postgres` only if this service also runs `askdb introspect` programmatically.

Load the schema and build the model once at startup, then call `ask()` per request:

```ts
// ask-handler.ts
import { ask, loadSchema } from "@askdb/core";
import { openai } from "@ai-sdk/openai";
import { Pool } from "pg";

// loadSchema is synchronous; it autodetects the artifact directory,
// a bundled .bundle.json, or a bare schema.json. Load once at startup.
const schema = loadSchema("./my-app.schema");
const model = openai("gpt-4o-mini");

// Connect as a read-only, least-privilege role, with a statement timeout.
const pool = new Pool({ connectionString: process.env.DATABASE_URL, statement_timeout: 5000 });
pool.on("error", (err) => console.error({ err }, "idle database client error"));

export async function askQuestion(question: string) {
  const { sql, tenantParams } = await ask({
    question,
    schema,
    dialect: "postgres",
    model,
  });

  // runReadOnly: copy the helper from the first example; it uses this pool.
  const rows = await runReadOnly(sql, tenantParams ?? []);
  return { sql, rows };
}
```

Every option `ask()` takes — modes, tenant scope, retrieval, sensitive-field handling — is in the [@askdb/core API reference](/reference/core-api/). On `askdb.ask(question, overrides)`, the question is the first argument and the other options are per-call overrides. `schema`, `model` and `dialect` take the client's forms, and `mode` and `omitSensitiveIdentifiersFromNlToSqlPrompt` can only tighten what the config sets. See [`AskOverrides`](/reference/client-api/#overrides--askoverrides).

## Run the SQL it returns

AskDB returns checked SQL; your handler logs it, runs it, and returns the result. `runReadOnly` reads every row the query returns. To cap the rows, use `runCapped` from [Cap the rows a query returns](/guides/cap-the-rows-a-query-returns/), as the [Express example](#complete-example-express-server) below does.

`askdb.ask()` and `ask()` both return the query in two forms, each with its own array. Run `sql` with `tenantParams`, the tenant IDs for its markers, which it has only when you pass a tenant scope. Or run `unboundSql` with `params`, which binds every value as a parameter. Never mix the two arrays. `unboundSql` comes with `parameterize` on, the default; set `parameterize: false` to save the output tokens it costs. The result also has `verdict`, what AskDB's SQL checks found, and `usage`, the token counts when your provider reports them. [Result — `AskPipelineResult`](/reference/core-api/#result--askpipelineresult) lists every field.

<Aside type="note">
This example uses `pg` to run the SQL, but the driver is your choice — AskDB never opens a connection. If you already use an ORM or query builder (Prisma, Drizzle, Sequelize, Knex, …), skip `pg` entirely and pass the returned `sql` string and its values (`tenantParams ?? []`) to your existing client, e.g. `prisma.$queryRawUnsafe(sql, ...values)` or `db.execute(sql, values)`.
</Aside>

To run the same query again with a new value, such as another month, without a model call, see [Rerun a query with new values](/guides/rerun-a-query-with-new-values/).

<Aside type="caution">
AskDB's SQL checks catch common model mistakes but aren't a security boundary. Connect `DATABASE_URL` as a read-only, least-privilege role and keep `statement_timeout` set. See [Run generated SQL safely](/concepts/safety-boundaries/#run-generated-sql-safely).
</Aside>

## Switching engines

With `createAskDb()`, the dialect follows the engine the schema artifact recorded at introspection, unless `askdb.config.ts` sets `dialect`. With `ask()`, change `dialect: "postgres"` to `"cockroachdb"`, `"mysql"`, `"mariadb"`, `"sqlite"` or `"sqlserver"`. See [Switch engines](/guides/switch-engines/) for the full migration matrix.

## Complete example: Express server

The snippet below is a copy-paste-ready Express server. Schema, model, and dialect are fully config-driven — `askdb.config.ts` sets `host.schemaPath` and the AI provider; `server.ts` only handles HTTP.

The `/ask` endpoint accepts an optional `execute` flag: `false` (default) returns just the SQL; `true` also runs it and returns the rows. It runs the SQL the way [Run safely in production](/guides/run-safely-in-prod/) describes: under a read-only role with a statement timeout, inside a read-only transaction, and capped at 1,000 rows ([Cap the rows a query returns](/guides/cap-the-rows-a-query-returns/)). Errors go to the server log under a correlation ID; the caller gets that ID and a generic message, because an error can carry provider or schema details.

```ts
// server.ts
import { randomUUID } from "node:crypto";
import { createAskDb } from "@askdb/client";
import { bootstrapAskDbEnv, getAskDbRuntimeConfig } from "@askdb/config";
import express, { type Request, type Response } from "express";
import pg from "pg";

bootstrapAskDbEnv({ cwd: process.cwd() });

const app = express();
app.use(express.json());

const askdb = createAskDb({
  config: getAskDbRuntimeConfig(),
  // schema resolved from host.schemaPath in askdb.config.ts
});

// Connect as a read-only, least-privilege role, with a statement timeout.
const pool = process.env.DATABASE_URL
  ? new pg.Pool({ connectionString: process.env.DATABASE_URL, statement_timeout: 5000 })
  : null;
// An idle client whose connection drops emits on the pool; without a listener, the process exits.
pool?.on("error", (err) => console.error({ err }, "idle database client error"));

const ROW_CAP = 1000;

// Runs one generated statement in a read-only transaction and reads at most
// ROW_CAP rows, as in the docs' "Cap the rows a query returns" guide.
async function runCapped(db: pg.Pool, sql: string, params: unknown[] = []) {
  const client = await db.connect();
  const onError = () => undefined;
  client.on("error", onError);
  try {
    await client.query("BEGIN READ ONLY");
    // A variable, not an inline object: @types/pg doesn't declare queryMode.
    const declare = { text: `DECLARE askdb_rows NO SCROLL CURSOR FOR ${sql}`, values: params, queryMode: "extended" };
    await client.query(declare);
    const { rows } = await client.query(`FETCH ${ROW_CAP + 1} FROM askdb_rows`);
    return { rows: rows.slice(0, ROW_CAP), truncated: rows.length > ROW_CAP };
  } finally {
    await client.query("ROLLBACK").catch(() => undefined);
    client.off("error", onError);
    client.release();
  }
}

app.post("/ask", async (req: Request, res: Response) => {
  const correlationId = randomUUID();
  const { question, execute } = (req.body ?? {}) as { question?: unknown; execute?: unknown };

  if (typeof question !== "string" || question.trim() === "") {
    res.status(400).json({ correlationId, error: "question is required and must be a non-empty string" });
    return;
  }

  if (execute !== undefined && typeof execute !== "boolean") {
    res.status(400).json({ correlationId, error: "execute must be a boolean when provided" });
    return;
  }

  if (execute && !pool) {
    res.status(500).json({ correlationId, error: "DATABASE_URL is not configured" });
    return;
  }

  // Errors can carry provider or schema details: log them, and send the caller a generic message.
  let result;
  try {
    result = await askdb.ask(question.trim());
  } catch (err) {
    console.error({ correlationId, question, err });
    res.status(500).json({ correlationId, error: "Could not generate SQL for this question. See the server log for this correlationId." });
    return;
  }

  // `sql` runs with `tenantParams` (none here: this server passes no tenant scope).
  const { sql, tenantParams } = result;
  console.log({ correlationId, question, sql, execute: execute === true });

  if (!execute) {
    res.json({ correlationId, sql });
    return;
  }

  try {
    const { rows, truncated } = await runCapped(pool!, sql, tenantParams ?? []);
    res.json({ correlationId, sql, rows, truncated });
  } catch (err) {
    console.error({ correlationId, sql, err });
    res.status(500).json({ correlationId, sql, error: "The query failed. See the server log for this correlationId." });
  }
});

app.get("/health", (_req: Request, res: Response) => {
  res.json({ status: "ok" });
});

app.listen(3000, () => console.log("listening on http://localhost:3000"));
```

```ts
// askdb.config.ts
import { defineConfig, env, type AskDbConfig } from "@askdb/config";

export default defineConfig({
  ai: {
    provider: "openai",
    providerConfig: { openai: { apiKey: env("OPENAI_API_KEY") } },
  },
  introspection: {
    provider: "postgres",
    providerConfig: { postgres: { databaseUrl: env("DATABASE_URL") } },
  },
  host: {
    schemaPath: env("ASKDB_SCHEMA_PATH"),
  },
} satisfies AskDbConfig);
```
