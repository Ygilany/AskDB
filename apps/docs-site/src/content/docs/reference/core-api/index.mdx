<p class="doc-eyebrow">Reference · @askdb/core</p>

<p class="doc-lede"><code>@askdb/core</code> is the NL-to-SQL pipeline. It owns schema loading, prompt construction, the built-in dialects, heuristic SQL checks, and tenant-scope validation and binding. Everything else in the AskDB ecosystem composes it.</p>

## Where to start

| To | Use | Page |
| --- | --- | --- |
| Turn a question into SQL | `ask()` | [ask()](/reference/core-api/ask/) |
| Rerun a stored query with new values | `bindPreparedQuery()` | [bindPreparedQuery()](/reference/core-api/rebind/) |
| Load a schema artifact | `loadSchema()` | [Schema loading](/reference/core-api/schema/) |
| Scope queries to a tenant | `TenantScope`, `expandTenantScope()` | [Tenant scope](/reference/core-api/tenancy/) |
| Check SQL that didn't come through `ask()` | `validateSensitiveReferences()`, `validateSelectSql()`, `validateTenantGuardrails()` | [Checks](/reference/core-api/checks/) |
| Change how a built-in engine is prompted and checked | `DialectSpec` | [Dialects](/reference/core-api/dialects/) |
| Log each stage | `createAskDbLogger()` | [Logging](/reference/core-api/logging/) |
| Catch what it throws | `AskDbError` and its subclasses | [Errors](/reference/core-api/errors/) |

`@askdb/client`'s `createAskDb()` calls `ask()` with the settings in `askdb.config.ts`; see [@askdb/client API](/reference/client-api/).

## Internal exports

`@askdb/core` also exports these for AskDB's own packages and tests. They aren't part of the documented API, and they have no stability promise.

| Export | What it is | Used by |
| --- | --- | --- |
| `tenantPolicyFrontmatterSchema`, `tenantScopeSchema` | The zod schemas for `tenant-policy.md` front-matter and for a `TenantScope` | Studio |
| `v2SchemaJsonSchema` | The zod schema for `schema.json` | `@askdb/enrich` |
| `enforcementModeSchema`, `hierarchyEdgeSchema`, `polymorphicTableSchema`, `scopedTableSchema`, `tenantAccessSchema`, `tenantRootSchema`, `v2ColumnFrontmatterSchema`, `v2ColumnSchema`, `v2ConceptSchema`, `v2ConceptsFrontmatterSchema`, `v2TableFrontmatterSchema`, `v2TableSchema` | The other zod schemas behind the loaders | `@askdb/core` only |
| `normalizeTenantPolicy` | Checks a parsed tenant policy against `schema.json` and collects its problems | `@askdb/enrich` |
| `RECOGNIZED_H2_SECTIONS`, `TENANT_POLICY_H2_SECTIONS` | The `##` headings the table and tenant-policy parsers recognize | `@askdb/core` only |
| `assertNlToSqlInputs` | The question and schema check `ask()` runs before the model call | `@askdb/core` only |
| `buildNlToSqlSystemPrompt` | The NL→SQL system prompt | `@askdb/core` only |
| `buildSelectGuardrailExplanation` | Builds the `explain` summary of a statement that passed the read-only check | `@askdb/core` only |
| `escapeSqlLiteral` | Escapes a value as a SQL literal for a dialect | `@askdb/core` only |
| `extractTenantPlaceholders` | Lists the `:tenant_*` placeholders in SQL | `@askdb/core` only |
| `formatAskDbModesV1` | Formats the list of modes for a message | CLI |
| `formatSupportedAskDbLogLevels`, `isSupportedAskDbLogLevel` | Log-level helpers | CLI |
| `parseAskDbSchemaJson`, `loadNormalizedSchemaFromJson`, `normalizeAskDbSchema`, `AskDbSchemaFile` | The older v1 schema format: parse, load and normalize it, and its file's type | `@askdb/core` only |
