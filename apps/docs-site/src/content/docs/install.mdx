<p class="doc-eyebrow">Start · Install</p>

<p class="doc-lede">AskDB is a set of focused packages — install only what your use case needs. Pick your path below; each guide starts with the exact install commands, and the <a href="/reference/packages/">package reference</a> covers every package individually.</p>

Upgrading from an earlier release? [Upgrade AskDB](/guides/upgrading/) shows the steps, and [Upgrade notes by release](/reference/upgrade-notes/) lists what to change for each release.

On the day an AskDB version is published, `pnpm dlx askdb@latest` and `yarn dlx askdb@latest` install an older one. pnpm 11 and later, and Yarn 4.18, skip versions less than a day old by default (pnpm's `minimumReleaseAge`, Yarn's `npmMinimalAgeGate`). npm installs the new version at once. Step 2 of the [Quickstart](/quickstart/#2-install-askdb-and-scaffold-the-config) shows the setting that lets pnpm and Yarn install AskDB's newest release.
