# Docs tools

Where to find content, navigation, and redirects in common docs tools. Confirm against the project's config — versions move these around.

| Tool | Detect by | Content | Navigation | Redirects |
|---|---|---|---|---|
| **Astro Starlight** | `@astrojs/starlight` in `astro.config.*` | `src/content/docs/` | `sidebar` in the `starlight()` config; `autogenerate` groups read from directories | `redirects` in `astro.config.*` |
| **Docusaurus** | `docusaurus.config.*` | `docs/` (plus `blog/`, versioned `versioned_docs/`) | `sidebars.*`; `_category_.json` for autogenerated folders; `sidebar_position` front matter | `@docusaurus/plugin-client-redirects` |
| **VitePress** | `.vitepress/config.*` | project root or configured `srcDir` | `themeConfig.sidebar` and `nav` | `rewrites`, or the host's redirect config |
| **MkDocs / Material** | `mkdocs.yml` | `docs/` | `nav:` in `mkdocs.yml` (or `awesome-pages` `.pages` files) | `mkdocs-redirects` plugin |
| **Nextra** | `nextra` in `next.config.*` | `pages/` or `content/` | `_meta.{js,ts,json}` per folder | `redirects()` in `next.config.*` |
| **Mintlify** | `mint.json` / `docs.json` | project root | `navigation` in the config | `redirects` in the config |
| **Fumadocs** | `fumadocs-*` packages | `content/docs/` | `meta.json` per folder | Next.js `redirects()` |
| **Sphinx** | `conf.py` | `source/` or `docs/` | `toctree` directives | `sphinx-reredirects` |
| **GitBook** | `.gitbook.yaml` | configured `root` | `SUMMARY.md` | `redirects` in `.gitbook.yaml` |
| **Plain Markdown** | none of the above | `docs/` | a hand-written index / README | none — keep old paths as stubs linking to new ones |

## Components worth using

Most tools ship equivalents of these; use the tool's own, matching how existing pages use them.

- **Steps** — tutorials and how-to procedures.
- **Tabs / code groups** — per-language, per-package-manager, or per-platform variants in how-tos.
- **Callouts / admonitions** — real hazards and prerequisites; keep them rare so they keep their weight.
- **Cards / link grids** — landing pages and "next steps".
- **Generated API reference** — TypeDoc, OpenAPI, and autodoc plugins where the tool supports them.
