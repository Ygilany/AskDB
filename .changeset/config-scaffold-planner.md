`@askdb/config/scaffold` exports `planAskDbScaffold`, the planner `askdb init` and Studio's setup wizard share (#711). It takes a new project's answers (engine, connection variable or SQLite file, Prisma schema path, schema directory, `ai` block, RAG store, Studio execute) and the `@askdb/config` and `@askdb/prisma` specs to install, and returns the `askdb.config.ts` source, the `.env.example`, the env vars the config reads, and the packages to install. It's pure. It throws `AskDbScaffoldInputError`, whose `field` names the answer, for an env var name that isn't uppercase POSIX (`^[A-Z_][A-Z0-9_]*$`), a control character in a path, an unknown id or a missing answer. Also exported: `isAskDbScaffoldEnvName(name)`, the planner's env var name rule, and the `AskDbScaffoldAnswers`, `AskDbScaffoldPlan` and `ScaffoldValue` types. For a Prisma project the plan installs `ai` (the newest major `@askdb/core`'s peer accepts) and `zod` (core's range) next to `@askdb/prisma`, which Yarn Plug'n'Play needs (#760). The `@askdb/config/scaffold` entry point is experimental: a minor release of `@askdb/config` may change it (ADR 0030).
