The package reference's dependency diagram is redrawn in D2 from its "Dependency direction" table (#713). The old hand-drawn diagram predated the `@askdb/ai`, `@askdb/client` and `@askdb/config` split, and showed `askdb`, Studio and the HTTP API depending on a Postgres connector. The new one sits beside the table it illustrates and follows the site's light and dark toggle. `STYLE.md`, `custom.css` and ADR 0034 now link the two upstream issues behind the diagram workarounds (HiDeoo/astro-d2#69, withastro/astro#18652).
