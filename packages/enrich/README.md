# @askdb/enrich

Shared schema artifact enrichment workspace helpers used by AskDB authoring surfaces.

This package owns the non-UI enrichment model: loading and saving schema artifact workspaces, building editable table drafts, preserving markdown sections, and building AI suggestion targets and context.
